Summary

Desktop Organizer 1.1.0 is built, tested and packaged for Windows, but not yet published or sold. It sorts files in the Desktop, Downloads, Documents or any chosen folder into a folder structure the user picks, and every run can be undone.

  • Built: a Windows app with an installer and portable zip, 93 automated tests, and two tagged releases (1.0.0 and 1.1.0, both on 5 October 2026).
  • Pricing: every feature is free for now; the Free vs Premium split is planned but not switched on.
  • Before launch: licensing and payments, auto-update, and code signing so Windows stops warning about the installer.

The code is on the desktop-app branch with tags v1.0.0 and v1.1.0. It has not been pushed to GitHub or merged into master.

Business model

The plan is a generous free tier that people keep using, and a one-time or monthly Premium upgrade for automation. Nothing is gated yet; the split below is the proposal.

Organize the Desktop with one clickAny folder (Downloads, Documents, drives)

Exclusions, light and dark themeAuto-organize, tray, start with Windows
Duplicate finder, stats
  • Proposed price: about US$15–25 one-time, or about US$3 a month. These figures are a starting estimate, not market-tested.
  • Payments: a merchant-of-record service such as Lemon Squeezy or Paddle, which handles global sales tax and issues license keys. This matters from Jamaica, where Stripe is not directly available (to confirm before choosing).
  • Trial: 14 days of Premium on first install.
  • Locked features: shown with a lock icon that opens the upgrade screen, rather than hidden.

SWOT

The product is ahead of its distribution: the strengths are in the app, while the weaknesses are reach and trust.

The weaknesses and threats share one fix list: code signing, a clear free tier, and the safety features shown up front.

Risks

The biggest risk is moving a user's files somewhere they did not expect; most of the design exists to make that recoverable.

RiskHow it's handled
Files moved to the wrong placePreview before every manual run; every move logged and undoable; nothing overwritten; extra copies go to the Recycle Bin, never deleted
Breaking a project or system folderRefuses drive roots, the user folder and system folders; warns before code and Docker projects
Moving a file that is still downloadingUnfinished downloads are skipped; auto-organize waits until a file has stopped changing
“Windows protected your PC” warning scares buyersCode signing planned before launch; until then, a note in the user guide
Antivirus flags the appBuilt as a folder rather than one self-extracting file; signing and submitting to Microsoft reduces it further
Licence keys get shared or crackedKeep protection simple; desktop licences can always be bypassed, so effort goes into the product

During development a test once moved 47 real Desktop files. They were all restored, and the tests now use fake folders only.

Decisions needed

Six decisions block the move from a finished app to a product on sale.

  • Choose the payment and licensing service (Lemon Squeezy, Paddle or another) and confirm it pays out to Jamaica.
  • Set the Premium price and whether it is one-time, monthly or both.
  • Confirm which features stay free (see Business model).
  • Buy a code-signing certificate, or accept the Windows warning for an early release.
  • Push the code to GitHub and merge the desktop-app branch into master.
  • Agree the positioning: the safest organizer for Windows, one-time price, nothing sent online.
